# Raziskovanje-odprtokodnega-projekta-Godot-Engine
Odprtokodni program za izdelavo 2D in 3D računalniških iger, pri katerem sodelujejo programerji z vsega sveta.
3. DEL – RAZISKUJ ODPRTOKODNI SVET

Odprtokodni projekt: Godot Engine

GitHub repozitorij: https://github.com/godotengine/godot
Licenca: MIT (odprtokodna licenca)

1. Kaj je projekt in kdo sodeluje pri njem?

Godot Engine je brezplačen program za izdelavo 2D in 3D računalniških iger. Uporabnikom omogoča ustvarjanje različnih iger, dodajanje animacij, zvokov in drugih elementov. Vsebuje tudi urejevalnik kode, v katerem lahko programiramo. Za programiranje uporablja predvsem svoj jezik GDScript, podpira pa tudi C# in C++.

Projekt sta začela razvijati Juan Linietsky in Ariel Manzur. Danes pri razvoju sodelujejo organizacija Godot Foundation in številni prostovoljni programerji z vsega sveta. Vsak lahko pomaga pri izboljševanju programa, iskanju napak ali pisanju dokumentacije.

2. Zakaj se mi zdi zanimiv?

Godot se mi zdi zanimiv, ker me zanima programiranje in izdelovanje računalniških iger. Pri pouku se učimo programirati v Javi, zato bi bilo zanimivo preizkusiti še drug programski jezik. Zanimivo se mi zdi tudi, da lahko z lastnim programiranjem ustvarimo igro, ki jo lahko nato tudi sami preizkusimo. Program je brezplačen in dostopen vsem, zato ga lahko uporablja vsak, ki se želi naučiti izdelovati igre.

3. Kako projekt uporablja GitHub?

Godot uporablja različne funkcije GitHuba, ki razvijalcem omogočajo skupno delo:

Commits: Z njimi razvijalci shranjujejo spremembe v programski kodi. Tako lahko spremljajo, kaj so spremenili in kdaj.

Issues: Uporabniki lahko prijavijo napake v programu ali predlagajo nove funkcije.

Branches: Omogočajo razvijalcem, da delajo na različnih izboljšavah, ne da bi pri tem spreminjali glavno različico programa.

Pull Requests: Ko razvijalec dokonča svojo spremembo, jo lahko predlaga za vključitev v glavni projekt. Drugi razvijalci jo pregledajo in se odločijo, ali jo bodo sprejeli.

Zaključek: Godot Engine je dober primer odprtokodnega projekta, pri katerem lahko sodelujejo programerji z vsega sveta. Zanimiv se mi zdi predvsem zato, ker združuje programiranje in ustvarjanje računalniških iger.
